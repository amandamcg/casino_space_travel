# Fonts

The page is set in ABC Areal Mono (Dinamo), under Amanda's licence. The font file,
`ABCArealMono-Regular.woff2`, is deliberately **not in this repository**: Dinamo's terms
(version 2.51, §10) forbid putting the fonts in public repositories, and this one is
public. Until it is served some other way the page falls back to the system monospace,
which the CSS allows for.
