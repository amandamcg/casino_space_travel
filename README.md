# casinospacetravel.com

The site is one page: the fractal from Show 8, live, thrown onto a dark field, with
lampshade-like stones over it that cast shadows; moving the mouse or tilting a phone moves
the light. Hand-lettered mark, the dates, and links to Bandcamp and the email.

Served by GitHub Pages from `main`; the `CNAME` points the domain here. Plain files, no
build step: `index.html`, `js/` (the show's own fractal renderer and the page's script),
`img/` (the traced mark), `fonts/` (see its README: the licensed font is not in git).

The page is made in the `casino_space_travel_video` repository as `show 8/experience.html`
and copied here; change it there, then copy `experience.html` to `index.html` along with
`js/experience.js`, `js/flame.js`, `js/genome.js`, `js/palettes.js`, `js/rng.js`,
`js/settings.js` and `img/casino-space-travel.svg`.
